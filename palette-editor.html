StressWatchFace — Palette Editor

Edit the heart-rate gradient palettes. Each palette is an ordered list of colors — lowest HR uses the leftmost color, highest HR uses the rightmost. Only the 64 watch-displayable colors are shown (4 levels per RGB channel).

Raw JSON (preview)
How this hooks up to the watch app

Save the downloaded file as palettes.json in the repo root, then run ./build.sh. The build wrapper calls gen-palettes.py which writes source/PalettesGenerated.mc, then monkeyc compiles it into the .prg. On the watch, Customize → Settings → Palette lets you pick which palette is active.
